# Sources

- [HackHarvard 2026 event site](https://hhuh.io/): schedule, submission deadline, and the Best Use of Daytona and Make It Legendary requirements.
- [LeRobot SO-101 guide](https://huggingface.co/docs/lerobot/so101): ports, motor setup and calibration commands.
- [LeRobot robots API reference](https://huggingface.co/docs/lerobot/main/api/robots): follower options such as `use_degrees` and `max_relative_target`.
- [SO-ARM101 Pro assembled kit](https://openelab.io/a/s/products/seeed-studio-so-arm101-pro-assembled-kit-lerobot-6dof-robotic-arm) and [Seeed kit listing](https://pakronics.com.au/products/so-arm101-low-cost-ai-arm-servo-motor-kit-pro-for-lerobot-assembled-version-ss100046482): leader and follower arms, STS3215 encoder servos, 12 V and 5 V supplies.
- [SO-ARM101 teleoperation write-up](https://dev.classmethod.jp/en/articles/lerobot-so-arm101-assembly-teleop/): teleoperation command and ports changing between replugs.
- [TheRobotStudio SO-ARM100 repository](https://github.com/TheRobotStudio/SO-ARM100): SO-101 URDF and MuJoCo model.
- [NVIDIA SO-101 reach policy](https://huggingface.co/nvidia/so101-reach): RL reaching trained in simulation and validated on a real SO-101.
- [xAI Voice Agent API](https://docs.x.ai/developers/model-capabilities/audio/voice-agent) and the [xAI cookbook web voice example](https://github.com/xai-org/xai-cookbook/tree/main/voice-examples/agent/web): endpoint, ephemeral tokens, function-call and audio events.
- [Daytona Python SDK](https://pypi.org/project/daytona/): sandbox creation, snapshots, process execution, file upload.
- [Claude Code: CLAUDE.md and rules](https://code.claude.com/docs/en/memory.md): where CLAUDE.md loads, the 200-line target, imports, and path-scoped `.claude/rules/`.
- [Claude Code: skills](https://code.claude.com/docs/en/skills.md): `.claude/skills/<name>/SKILL.md`, `$ARGUMENTS` and `disable-model-invocation`.
- [Claude Code: permissions](https://code.claude.com/docs/en/permissions.md): allow, ask and deny rules and their precedence.
- [Claude Code: best practices](https://code.claude.com/docs/en/best-practices.md): verification commands, plan mode, `/clear`, and specs that end in an end-to-end check.
- [Baymax on Devpost](https://devpost.com/software/baymax-your-personal-healthcare-companion), [Stanford Daily on TreeHacks 2024](https://stanforddaily.com/2024/02/27/treehacks-2024/), and [Robosurge on Devpost](https://devpost.com/software/we-use-nix): prior TreeHacks arm projects.
